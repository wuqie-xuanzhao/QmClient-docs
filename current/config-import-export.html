保存与加载

保存

  • CConfigManager::Save() 会按配置域打开临时文件，必要时创建 QmClient/ 目录。
  • 只有 HasVars=true 的域会序列化配置变量；回调数据通过 RegisterCallback() 分域写入。
  • 写入成功后执行 io_sync、io_close，再把临时文件 rename 为正式文件。
  • 未知命令只回写到 DDNET 域。

加载

  • 启动时遍历全部配置域，先迁移 legacy 文件，再选择当前路径或 legacy 路径执行。
  • 配置文件逐行作为 console command 执行，所以回调写出的 add_profile、bindchat、update_war_group 等也是加载协议。
  • 配置域加载完成后，才执行 autoexec_client.cfg；不存在时回退到 autoexec.cfg。
