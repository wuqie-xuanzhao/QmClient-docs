QmClient 聊天翻译按钮现状

当前按钮是聊天输入框旁的出站翻译控制入口，不是每条历史消息行尾的逐条按钮。入站消息翻译主要由 translate / translate_id 命令、自动入站翻译和聊天行翻译响应字段承载。

当前结论

能力状态维护口径
输入框侧翻译按钮已实现按钮随聊天输入框渲染，占用输入框右侧宽度，使用语言图标。
左键语言菜单已实现左键点击按钮打开语言/出站翻译相关弹出菜单。
右键自动出站翻译已实现右键点击按钮切换 qm_translate_auto_outgoing。
发送前自动翻译已实现SendChatQueued(..., AllowOutgoingTranslation=true) 会先检查自动出站翻译。
目标语言后缀翻译已实现TryTranslateOutgoingChat() 解析用户输入中的目标语言标记，再发送翻译结果。
历史消息逐条行尾按钮未作为当前实现当前已有右键行菜单和翻译命令路径，但不是每条历史消息右侧独立翻译按钮。

按钮交互

CChat 在渲染聊天输入框时缩减输入文本宽度，在右侧放置翻译按钮。按钮区域用聊天坐标系命中检测，优先处理鼠标事件，避免穿透到输入框选择、聊天提交或其它弹窗。

交互当前行为
位置输入框文本裁剪区域右侧，大小由聊天字体缩放计算，最小约 16px。
左键按下并释放在按钮内时调用 OpenLanguageMenu()。
右键按下在按钮内时调用 ToggleAutoTranslate()，直接切换出站自动翻译。
颜色启用色、禁用色、菜单色和选中/普通选项色由 qm_translate_*_color 配置控制。
Tooltiphover 时显示右键启用/禁用自动翻译的提示。
菜单定位语言菜单以按钮位置换算到 UI 坐标，并限制在屏幕内。

出站翻译

路径当前行为边界
自动出站翻译ShouldAutoTranslateOutgoing() 检查开关、空文本、命令文本、数字文本和目标语言启发式匹配。以 qm_translate_auto_outgoing、qm_translate_auto_outgoing_mode 和 qm_translate_outgoing_target 为主。
发送前替换StartAutoOutgoingTranslate() 创建出站翻译任务；任务完成后用翻译结果再次调用 SendChatQueued(..., false)。队列满或后端无效时会回退发送原文。
显式目标语言TryTranslateOutgoingChat() 解析输入中的目标语言标记，并在翻译前提示正在翻译。这条路径不是按钮本身，但属于同一出站翻译体验。
发送队列SendChatQueued() 仍保留原聊天发送节流和历史记录。翻译结果最终仍通过普通聊天发送，不是跨服聊天或单独消息通道。

入站翻译

入站翻译不是通过“每行右侧按钮”作为当前主要入口。当前能力是：命令翻译最近消息或指定 ID、自动入站翻译、以及把翻译响应挂到聊天行对象上。

能力当前行为
translate翻译最近一条消息，可选按玩家名筛选。
translate_id翻译指定 client id 的最近消息。
自动入站翻译qm_translate_auto 开启后，对非本地、非服务器消息进行启发式过滤后翻译。
响应承载CChat::CLine 通过 m_pTranslateResponse 和 m_TranslationId 管理翻译结果、错误和行复用安全。
FTAPI 过载保护FTAPI 自动翻译默认需要额外开关，避免过载。

配置与设置

配置用途
qm_translate_backend翻译后端，当前包括 LLM、TencentCloud、LibreTranslate、FTAPI 等路径。
qm_translate_target / qm_translate_source入站翻译目标语言和源语言。
qm_translate_auto自动翻译收到的消息。
qm_translate_auto_outgoing自动翻译发送消息，也是按钮右键切换的核心状态。
qm_translate_auto_outgoing_mode出站自动翻译触发模式。
qm_translate_outgoing_target出站翻译目标语言。
qm_translate_btn_color_* / qm_translate_menu_*按钮和语言菜单视觉颜色。

旧文档提到的 qm_translate_show_button 不应再作为当前核心开关；本轮源码复核未看到它。
