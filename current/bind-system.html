QmClient Bind 系统现状

本文接管旧 Bind 指令系统报告。当前 Bind 能力分三层：DDNet 原生键盘绑定、TClient/QmClient 维护的 Chat Binds、以及 Bind Wheel。它们共享“执行控制台命令”的目标，但数据结构、UI、配置域和风险边界不同。

当前结论 原生键盘绑定 Chat Binds Bind Wheel 仍是规划 复核证据

当前结论

模块状态当前口径
DDNet 原生 binds已实现CBinds 负责键盘/鼠标/修饰键组合到控制台命令的映射，是基础能力。
Chat Binds已实现CBindChat 支持 bindchat 等控制台命令、默认绑定、聊天输入触发和独立配置保存。
Chat Binds UI部分实现设置页只管理默认绑定组的触发名称；自定义绑定管理和命令编辑不是完整 UI 能力。
Chat Binds Tab 补全函数存在 / 未接入ChatDoAutocomplete() 已实现，但聊天框 Tab 处理没有调用它。
Bind Wheel已实现支持轮盘打开、hover 执行、添加/删除/清空、设置页编辑、圆形预览和快捷键绑定。
配置导入/导出规划Chat Binds 和 Bind Wheel 已各自保存，但统一导入/导出绑定配置仍应归到配置导入/导出规划。

原生键盘绑定

CBinds 是 DDNet 原生路径，QmClient 继续在此基础上运行。它用 m_aapKeyBindings[KeyModifier::COMBINATION_COUNT][KEY_LAST] 保存修饰键组合和键码对应的控制台命令，并用 m_vActiveBinds 追踪按住式绑定。

能力说明
修饰键组合支持 Ctrl、Alt、Shift、GUI 的组合 mask；部分组合会禁止无修饰键 fallback。
按住式命令按下执行 +command 1 语义，释放时执行对应释放逻辑；聊天、控制台和菜单打开时避免错误释放 active bind。
控制台命令bind、binds、unbind、unbindall 属于原生键盘绑定入口。
UI 绑定读取器TClient 设置页可通过 DoLine_KeyReader 为部分功能绑定命令，例如 +bindwheel。

Chat Binds

CBindChat 是聊天输入触发的命令替换层。用户在聊天框按回车时，聊天组件先调用 ChatDoBinds()，匹配成功则执行绑定命令并写入聊天历史，不再发送普通聊天消息。

项目当前实现边界
数据结构std::vector<CBind> m_vBinds，上限 256，名称 64 字节，命令 1024 字节。代码仍有 TODO use map，查找和保存排序仍基于 vector。
默认绑定Kaomoji、Warlist、Other 三组，包含 !shrug、!war、!translate、!mute 等。默认项多以 ! 开头，但代码没有强制所有自定义项必须用 ! 前缀。
匹配规则按输入文本第一个空格前的 token 与绑定名进行大小写不敏感匹配。用户若创建普通词作为绑定名，会拦截普通聊天。
持久化保存到 ConfigDomain::TCLIENTCHATBINDS；默认绑定未改时不写出，被删除的默认绑定写 unbindchat。这不是普通 DDNet bind 配置域，也不是统一 Qm 配置导出包。
设置页当前只渲染默认绑定组，每项可编辑触发名称。没有完整自定义绑定列表、命令编辑、删除按钮和搜索过滤 UI。
Tab 补全ChatDoAutocomplete() 能基于 m_aCompletionBuffer 查找绑定并替换输入。chat.cpp 的 Tab 处理当前只构建玩家/命令补全流程，未看到调用 m_BindChat.ChatDoAutocomplete()。

“Chat Binds 已实现”和“Chat Binds UI 已完整”不是一回事。当前可执行和持久化能力已经存在，但管理 UI 仍偏向默认绑定重命名。

Bind Wheel

CBindWheel 是轮盘式快捷命令组件，最多 64 项。它复用 emoticon selector 的鼠标/触控状态，按住 +bindwheel 打开，松开时可执行选中项。

能力当前实现
控制台入口+bindwheel、+bindwheel_execute_hover、add_bindwheel、remove_bindwheel、delete_all_bindwheel_binds；旧 bindwheel i[index] 入口标为 legacy。
运行时交互圆形菜单根据鼠标角度/距离选择项，支持开闭动画、hover 执行和释放时执行。
设置页编辑左侧编辑名称/命令并添加、覆盖、删除；右侧圆形预览支持左键选择、右键交换、中键只选不复制。
快捷键设置页用 DoLine_KeyReader 绑定 +bindwheel；默认能力落在原生 CBinds 上。
配置Bind Wheel 在 ConfigDomain::QMCLIENT 保存；tc_reset_bindwheel_mouse 和 tc_animate_wheel_time 控制鼠标重置与动画时长。

仍是规划

  • 把 m_vBinds 从 vector 改为 map 或其它查找结构。
  • 为 Chat Binds 强制或引导 ! 前缀，降低普通聊天误触发风险。
  • 把 ChatDoAutocomplete() 正式接入聊天框 Tab 补全，并处理和玩家名/服务器命令补全的优先级。
  • 补完整 Chat Binds 管理 UI：自定义绑定列表、命令编辑、删除、搜索、导入导出。
  • 将 Bind Wheel 扩展成“快捷设置面板/控制中心”仍是 planning，不是当前已实现；最小规格见 bindwheel-quick-settings-spec.html。
  • 多套按键配置文件和统一配置分享应走 配置导入/导出现状 的规划边界。
