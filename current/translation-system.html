① 当前结论

翻译系统已经不是单一腾讯云或单一智谱 API 的方案，而是一个 CTranslate 组件统一调度的多后端系统。默认后端配置为 qm_translate_backend = "llm"，LLM 内部再通过 provider 分流到 ZhipuAI、DeepSeek、OpenAI 或 Custom。

聊天行入站翻译、自动入站翻译、显式目标语言出站翻译、自动出站翻译和翻译按钮颜色设置都已有代码基础。仍不能把它写成“完整产品化翻译平台”：密钥仍是客户端配置项，网络失败只在聊天内反馈，且没有统一的后台任务面板、历史记录或 provider 健康检查页。

聊天输入框旁的翻译按钮交互已单独拆到 chat-translation-button.html。本页只记录翻译系统本体，不重复描述按钮 hitbox 和菜单渲染细节。

③ 后端与配置

当前后端由字符串配置选择：llm、tencentcloud、libretranslate、ftapi。无效字符串会导致后端创建失败，并在聊天中提示 Invalid translation backend。

后端配置与默认当前口径
LLMqm_translate_llm_provider：0=ZhipuAI、1=DeepSeek、2=OpenAI、3=Custom；默认模型分别为 glm-4.5-flash、deepseek-chat、gpt-4o-mini、空字符串。默认翻译后端。端点留空时使用内置 provider endpoint；必须配置对应 provider 的 API key。
TencentCloudqm_translate_tc_endpoint、qm_translate_tc_secret_id、qm_translate_tc_secret_key、qm_translate_tc_region。仍可选。旧文档里的 tc_translate_key 不再是当前主线。
LibreTranslateqm_translate_libre_endpoint 默认 http://localhost:5000，另有可选 qm_translate_libre_key。适合本地或自托管服务。
FTAPI公共服务路径仍保留，自动入站翻译由 qm_translate_ftapi_auto_enable 额外保护。默认不允许自动入站翻译，避免公共服务过载。

目标语言和源语言由 qm_translate_target、qm_translate_source 控制；出站自动翻译另有 qm_translate_auto_outgoing、qm_translate_auto_outgoing_mode、qm_translate_outgoing_target。

④ 运行流程

入站聊天翻译

  • 手动翻译通过 translate / translate_id 控制台命令，或聊天行交互，最终进入 CTranslate::Translate。
  • 任务保存聊天行索引、m_TranslationId 和共享响应对象，不再依赖旧报告里提到的裸聊天行指针。
  • OnRender() 轮询后端状态，完成后写回 CChat::CLine::m_pTranslateResponse 并重建聊天。

自动入站翻译

  • qm_translate_auto 开启后，AutoTranslate() 会跳过本机消息、服务器消息、本地玩家消息和以当前目标语言为主的文本。
  • FTAPI 后端默认拒绝自动入站翻译，并只提示一次保护说明。

出站翻译

  • TryTranslateOutgoingChat() 处理显式目标语言语法，创建 COutgoingTranslateJob 后再发送翻译结果。
  • ShouldAutoTranslateOutgoing() 受 qm_translate_auto_outgoing 控制，会跳过空文本、命令、纯数字和已匹配目标语言的文本。
  • 队列满或后端无效时，自动出站翻译会发送原文；显式目标语言翻译会提示错误并消耗本次发送动作。

⑤ 限制与边界

主题当前状态文档口径
并发控制qm_translate_llm_concurrency 非 0 时强制覆盖；自动模式下 ZhipuAI/DeepSeek 默认 3、OpenAI 默认 2、TencentCloud 默认 5、LibreTranslate 默认 2、FTAPI 默认 1。已有基础控制，不是无限队列。
生命周期OnReset() 和 OnShutdown() 会清空入站与出站任务。旧报告“缺少 OnReset/OnShutdown”的结论已过时。
聊天行安全任务写回前检查行索引、m_TranslationId 和响应对象是否仍匹配。旧报告里的悬空指针风险已被当前实现缓解。
协议翻译DDNet sixup_translate_* 属于 0.7/0.6 协议转换。不要和本页的自然语言聊天翻译混写。
密钥管理API key 和 Secret 仍通过客户端配置项保存。可以继续列为未来安全改进，不应写成已解决。
