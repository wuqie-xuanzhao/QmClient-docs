① 范围与可信度

本页基于 2026-06-16 当前工作区的文件结构做第一轮复核。它不声称覆盖所有功能细节，只修正旧文档中最容易误导后续维护的结构性问题。

范围当前判断
src/game/client/components/qmclient/translate/翻译系统已经是独立子目录，不再是旧文档中平铺的 translate.cpp/.h 口径。
src/game/client/components/qmclient/voice/语音模块已经是独立子目录，包含 voice_core、voice_utils、voice_component 和 voice_capture_pipeline。
src/game/client/QmUi/QmUi 仍是当前 UI 基础设施的一部分，包含 layout、animation、render bridge 等模块。
src/engine/shared/config_variables_qmclient.hQmClient 配置项集中在 qm_ 前缀体系，且包含性能、UI、IME、聊天日志、hitbox、中心服标识等较新的配置。

② 当前结构

QmClient 当前不应再被描述成一组散落功能点。更准确的结构是：DDNet/TClient 基础能力之上，叠加 QmClient 配置域、QmClient 设置页、QmUi 运行时、翻译/语音/社交/可视化等模块。

层代表路径说明
配置域src/engine/shared/config_variables_qmclient.h当前 QmClient 自有配置的主要入口，新增功能默认应继续使用 Qm/qm_ 口径。
设置页入口src/game/client/components/qmclient/menus_qmclient.cppQmClient 设置页和功能入口集中区域，后续 UI 文档应以这里的真实结构为准。
翻译系统src/game/client/components/qmclient/translate/包含后端、解析、UI 设置和出站翻译逻辑。
语音系统src/game/client/components/qmclient/voice/纯 C++ 语音链路仍是当前维护对象，后续文档要更新旧路径。
QmUisrc/game/client/QmUi/当前是 CUI 周边的布局、动画和 render bridge 基础设施，不应直接写成 Rust UI 已落地方向。
脚本与 gateqmclient_scripts/构建、文档检查、语言维护和性能报告入口在这里；旧脚本调研需要重新降级为背景资料。

③ 已确认事实

  • 翻译组件公开了 CTranslate，支持入站翻译、出站翻译、自动出站检测和并发 job 管理。
  • 语音核心配置快照已经使用 QmVoice* 命名，旧的 RiVoice* 或 Rust 双路径口径不应继续作为当前事实。
  • QmUi 的 CUiV2RenderBridge 当前记录 draw call 和 clip push 统计；文档应避免夸大为完整 retained render tree。
  • 配置项中已经出现 qm_perf_*、qm_ui_*、qm_chat_log_*、qm_hitbox_* 等新能力，旧总览的功能清单需要继续补齐。
