多语言系统源码分析

本页分析 QmClient 运行时语言包的维护链路：从 C++ 源码里的 `Localize`/`Localizable`/`Register` 文本提取，到模块化 TOML 维护库，再生成 `data/languages/*.txt` 并校验。

结论摘要

多语言系统的长期维护源不是 `data/languages/*.txt`，而是 `qmclient_scripts/languages_qmclient/translations/i18n/*.toml`。`extract_strings.py` 负责从 `src/` 提取 active source key，`generate_all.py` 读取 TOML store 并覆写运行时语言文件，`validate.py` 和 `review_duplicate_entries.py` 负责结构、缺失项和重复项审查。

聊天翻译系统是另一条业务链路，入口在 `src/game/client/components/qmclient/translate/`；它处理在线翻译 API，不负责生成 DDNet 运行时语言文件。

关联源码路径

路径职责维护口径
qmclient_scripts/languages_qmclient/source_keys.py扫描 `src/` 下 C/C++ 源码，提取 `Localize`、`Localizable` 和控制台 help 文本。active source key 的事实来源。
qmclient_scripts/languages_qmclient/extract_strings.py调用 `source_keys` 输出 `extracted_strings.txt` 和 `extracted_audit_report.json`。新增/删除本地化 key 后优先运行。
qmclient_scripts/languages_qmclient/i18n_store.py读写 `translations/i18n/*.toml`，按模块组织 message 和多语言 translations。TOML 维护库的读写层。
qmclient_scripts/languages_qmclient/generate_all.py把 active source key 与 TOML 翻译合成 `data/languages/*.txt`。运行时语言文件生成入口。
qmclient_scripts/languages_qmclient/validate.py解析生成产物和 TOML store，检查缺失翻译与文本风格审计。只读校验。
qmclient_scripts/languages_qmclient/review_duplicate_entries.py审查运行时语言文件中的空翻译、重复翻译、相似翻译和未使用项。只读人工审查辅助。

运行/调用流程

1. 源码提取`source_keys.py` 在 `src/` 中扫描 `.c/.cpp/.h/.hpp`，识别 `Localize`/`Localizable` 调用、`Register` help 文本和已知间接文本。
2. 提取产物`extract_strings.py` 排序输出 `extracted_strings.txt`，同时把字符串审计报告写入 `extracted_audit_report.json`。
3. 维护库读取`i18n_store.py` 从 `translations/i18n/*.toml` 读取模块化 message，identity 为 `(key, context)`。
4. 运行时生成`generate_all.py` 对 `GENERATED_LANGUAGES` 中登记的语言生成 `data/languages/*.txt`；缺失翻译回退到英文 source key。
5. 校验与审查`validate.py` 校验运行时文件和 TOML 缺失项，`review_duplicate_entries.py` 给出重复/相似/未使用项报告。

边界与风险

主题当前事实文档口径
维护源translations/i18n/*.toml 是人工维护源。不要手工把 `data/languages/*.txt` 当长期真相源。
生成产物generate_all.py 明确覆写 `data/languages/*.txt`。改运行时语言文件前应先回到 TOML store。
缺失翻译生成时按语言 map 查找，缺失时使用 source key 回退。运行时有回退不等于翻译完整。
脚本职责`validate.py` 与 `review_duplicate_entries.py` 是只读检查。审查报告用于人工收口，不能自动替代翻译审核。
在线翻译`translate_with_local_http.py` 生成 draft，显式 `--write-back` 才回填维护库。draft 需要审核，不应直接当最终翻译。
