Media Background 边界复核

本文修正 BC 移植状态页里“Media Background 未见实现”的粗口径：当前 QmClient 已有实体层视频背景和菜单 theme 视频背景基础，但还没有面向用户的“媒体背景管理/选择/产品化”闭环。

快速结论 当前已有能力 仍缺的产品化能力 后续规格边界 复核证据

快速结论

不能再把 Media Background 简单写成“源码未见实现”。更准确的口径是：底层图片/视频背景加载已存在，菜单背景也能从 theme 文件加载图片或视频；但没有独立的 Media Background UI、媒体库、导入/删除、音频策略、播放控制或资源页联动规格。

问题结论可信度
实体层背景是否支持视频？支持。cl_background_entities 可指向 .mp4/.webm/.mov/.mkv，由 CBackground::LoadVideoBackground() 加载。高
菜单背景是否支持视频 theme？支持。CMenuBackground::LoadMenuBackground() 会在 themes/ 下尝试 map、图片和视频扩展名。高
是否已有 BC 式 Media Background 产品功能？未见完整闭环。没有独立媒体库、选择器、导入/删除、播放控制或资源页媒体管理文档化入口。中高
是否应该和 3D Background 合并？不应合并。3D Background 是粒子背景，Media Background 是图片/视频/主题媒体来源与管理问题。高

当前已有能力

实体层背景图片/视频

  • BACKGROUND_VIDEO_EXTENSIONS 覆盖 .mp4、.webm、.mov、.mkv。
  • cl_background_entities 是实体层背景配置，cl_background_video_fps 控制实体层视频背景最大帧率。
  • CBackground::LoadBackground() 会区分当前地图、图片、视频和 map 背景；视频路径进入 LoadVideoBackground()。
  • 视频背景渲染走 RenderBackgroundTexture()，在 cl_overlay_entities == 100 的实体背景覆盖模式下渲染。

菜单 theme 图片/视频背景

  • cl_menu_map 仍是菜单背景选择入口，支持 auto、rand 和显式 theme 名称。
  • CMenuBackground::LoadMenuBackground() 会优先尝试 .map，然后尝试背景图片扩展名，再尝试视频扩展名。
  • 如果配置显式带视频扩展名，菜单背景会直接尝试 LoadVideoBackground()。
  • 菜单渲染中，如果 RenderBackgroundTexture() 成功，会直接渲染图片/视频纹理，不再走 map camera 动画。

资源页实体背景入口

  • 资源页已有 Entity Background Image tab，能通过 ApplyEntityBgSelection() 写入 cl_background_entities 并调用 m_Background.LoadBackground()。
  • 资源卡片对视频实体背景有 Video Background fallback 展示，说明 UI 已区分视频背景资源。

仍缺的产品化能力

缺口为什么重要当前边界
媒体库/导入 UI用户无法在 QmClient 文档层面找到“导入本地视频作为菜单背景”的稳定流程。底层路径可加载，不等于有完整资源管理体验。
菜单背景与资源页联动资源页 entity background 面向实体层，菜单 theme 面向 themes/；两者不是同一管理域。不能把 entity background 规格直接当菜单媒体背景。
播放控制与音频策略视频背景是否静音、暂停、循环、后台降载，都影响体验和性能。当前文档只确认视频帧渲染，不声明音频或播放控制。
性能预算菜单视频背景、实体视频背景、3D 粒子和资源预览可能同时消耗解码/GPU 上传预算。后续规格需要和页面切换卡顿、资源页 preview scheduler 一起审查。
跨平台解码边界视频背景依赖 CONF_VIDEORECORDER，Windows 还有 Media Foundation 路径。不能默认所有平台都稳定支持任意视频格式。

后续规格边界

阶段建议目标非目标
P0 文档修正把 BC 状态页修正为“已有底层视频背景，缺产品化 Media Background”。不改源码。
P1 菜单背景媒体说明补一个用户可读的 theme 图片/视频放置、命名、配置说明。不做资源市场、不做在线播放。
P2 本地导入/管理规格如果要开发，先定义导入目录、删除确认、缩略图、格式提示、错误状态和禁用开关。不引入远端服务、不播放网络 URL、不做版权/审核系统。
P3 性能与平台验收补 Windows/Linux/macOS 的格式支持和菜单切换性能验收。不把视频背景作为默认开启功能。

Media Background 不应通过“顺手接资源页上传/分享市场”实现。它首先是本地媒体来源、菜单 theme 和实体背景的边界整理问题。
