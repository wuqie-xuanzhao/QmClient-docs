Finish Prediction 边界调研

本文修正 BC 移植清单里的 Finish Prediction 口径：当前 QmClient 没有“预测何时到达终点”的功能。Race Time、Speedrun Timer、Split Timer、Gores 路线进度和 AntiPing 预测都不能等同为 Finish Prediction。

① 快速结论 ② 不应混淆的已有能力 ③ 风险边界 ④ 可行推进路径 ⑤ 源码证据

① 快速结论

Finish Prediction 当前应保持为“未见实现 / 不直接开发”。它需要从玩家当前位置、速度、路线、检查点和终点关系推导 ETA，和已有计时显示不是同一类功能。

问题结论可信度
当前是否已有 Finish Prediction？未见同名配置、渲染入口或功能模块。高
Speedrun Timer 是否等同于 Finish Prediction？不是。它是用户配置目标时长后的倒计时和过期自动 kill。高
Split Timer 是否覆盖 Finish Prediction？不是。Split Timer 规格只记录已经发生的分段，不预测未来完成时间。高
Gores 进度/距离场能否直接泛化为 Finish Prediction？不应直接泛化。它是特定地图路线/进度辅助，不是通用 DDNet ETA 模型。中高

② 不应混淆的已有能力

已有能力当前用途为什么不是 Finish Prediction
Race Time按 race start tick 计算当前 run 已用时间。只显示已经过去的时间，不估算终点 ETA。
Speedrun Timer按配置目标时长倒计时，过期后可自动 kill。目标时长来自用户配置，不来自地图路线或玩家状态预测。
Split Timer规划为本地 checkpoint 分段记录和 session best 对比。只记录已发生 split；规格明确不做自动 Finish Prediction。
Finish Name helperTClient 辅助逻辑会检测附近 finish tile 并改名。它检测邻近终点 tile，不预测剩余路线或完成时间。
Gores 路线进度/距离场基于地图 tile、tele、penalty/reward 等构建到终点的距离/进度辅助。它偏向 Gores 路线进度和调试，不是所有 DDNet 地图的公平通用 ETA。
AntiPing / prediction latency客户端网络预测、平滑和延迟显示。这是输入/网络预测，不是“到达终点”的成绩预测。

③ 风险边界

  • 不要改物理或预测：Finish Prediction 不能为了“更准”触碰协议、snapshot、物理、碰撞、rank 可达性或 demo 格式。
  • 不要把路线搜索做成默认优势工具：自动路线、ETA、可达性提示可能影响公平性，应先做单独设计和审查。
  • 不要把 Gores 进度场当通用基础：Gores 逻辑读取地图结构并处理特殊 tile；普通 DDNet、race、dummy/team 场景不能直接套用。
  • 不要和 Split Timer 合并：Split Timer 是过去分段数据；Finish Prediction 是未来状态估计，数据来源、风险和 UI 文案都不同。

默认结论：在没有独立规格、效果边界和公平性审查前，不应实现自动终点 ETA。

④ 可行推进路径

阶段允许做什么不做什么
P0 文档边界把 BC 状态页、TODO 路由和 Split Timer 规格统一到“Finish Prediction 未实现且需另行设计”。不改源码。
P1 被动信息整理如果继续推进，只能先整理当前 Race Time、checkpoint、Gores progress、status bar 现状。不做自动路线搜索或 ETA。
P2 明确 opt-in 原型若用户明确批准，可做本地、可关闭、非权威的实验性 ETA 原型，并标明误差和适用地图范围。不作为 rank、demo、服务端或共享成绩依据。

⑤ 源码证据

未见同名实现

在 src、data、CMakeLists.txt、cmake 和 qmclient_scripts 中检索 finish_prediction、RenderFinishPrediction、qm_finish 未发现功能入口；同一结论已同步到 BC移植状态.html。

Race Time 只是当前用时
  • src/game/client/gameclient.h:939-940 暴露 LastRaceTick() 和 CurrentRaceTime()。
  • src/game/client/gameclient.cpp:2189-2200 用 m_LastRaceTick 计算当前 race time。

  • src/game/client/components/tclient/statusbar.cpp:144-175 渲染 race time，而不是预测剩余完成时间。
Speedrun Timer 是目标倒计时
  • src/game/client/components/hud.cpp:945-1033 根据配置时长渲染倒计时、过期文案、自动 kill 和自动关闭。
  • src/game/client/components/hud.cpp:5723-5726 在 HUD render flow 中调用 RenderSpeedrunTimer()。
Gores 进度不是通用 ETA
  • src/game/client/components/tclient/tclient.cpp:3421-4146 构建 Gores 地图距离/进度字段，处理地图 tile、teleport、penalty 和 reward 等路线语义。
  • src/game/client/components/tclient/tclient.cpp:1604-1685 的 finish-name helper 是附近 finish tile 检测和改名辅助，不是未来完成时间预测。
  • src/game/client/components/tclient/statusbar.cpp:119-127 的 prediction 显示来自 Client()->GetPredictionTime()，属于网络/客户端预测耗时，不是 finish ETA。
