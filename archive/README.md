# Archive

这里保存已明显过时、错误或不再适合作为当前依据的历史文档。

优先使用 `index.html` 查看归档原因。归档文档只用于追溯历史思路。不要在实现、审查或规划中直接引用为当前事实。

`superseded-current/` 保存从 `../current/` 移出的同名 Markdown 来源材料。它们已由对应 HTML 现状页接管，只供追溯。

`superseded-planning/` 保存从 `../planning/` 移出的旧 Markdown 方案稿。它们已由对应 HTML 状态页接管，只供追溯。

`superseded-research/` 保存从 `../research/` 移出的旧 Markdown 调研原文。它们已由对应 HTML 状态页接管，只供追溯。
