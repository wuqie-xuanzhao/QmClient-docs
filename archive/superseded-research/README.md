# Superseded Research Notes

这里保存从 `research/` 移出的旧 Markdown 调研原文。

这些文件已由 `../../research/*.html` 状态页接管。它们保留用于追溯当时的观察和证据，但其中的路径、结论、风险判断和优先级可能已经随当前代码变化而过时。

维护规则：

1. 日常阅读优先使用 `../../research/index.html`。
2. 旧 Markdown 只作为来源材料；引用前必须核对对应 HTML 状态页和当前源码。
3. 如果调研内容需要转为当前实现依据，应重新写入 `current/` 或新的规格/计划，而不是继续扩写这些旧原文。
