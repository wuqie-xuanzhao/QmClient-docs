# Superseded Current Reports

这里保存从 `current/` 移出的同名 Markdown 来源材料。

这些文件已经由 `../../current/*.html` 现状页接管。它们保留用于追溯旧判断、代码证据来源和整理过程，但不再作为当前功能状态的权威入口。

维护规则：

1. 新增或修正当前事实时，优先更新 `../../current/*.html`。
2. 如果需要引用旧 Markdown，只能作为历史来源材料，并应同时核对对应 HTML 和当前源码。
3. 如果旧 Markdown 中的结论已被确认完全错误，保留在这里即可，不要重新移回 `current/`。
