.qmconfig 最小配置包小规格

本页把新版 TODO 中“配置导入/导出”的方向收敛为一个 P0 小规格：只打包 QmClient 已拆分出的配置域文件和 manifest，提供备份/迁移闭环；不做智能合并、逐变量选择、云同步或账号系统。

① 目标与非目标 ② 包结构 ③ P0 导出范围 ④ 导入策略 ⑤ 验收 ⑥ 当前证据

① 目标与非目标

类型范围理由
目标导出一个本地 .qmconfig 文件，内含 manifest 和选择的 QmClient 配置文件副本。当前已有稳定配置域和文件路径，P0 可以从文件级备份做闭环。
目标导入前显示 manifest 摘要，导入时先备份当前文件，再替换文件级配置。避免直接执行未知 cfg 命令造成不可恢复状态。
暂不做逐变量选择、冲突合并、三方 merge、变量级版本迁移。当前加载机制是执行 cfg 文件，不适合在 P0 里强行做变量级合并。
暂不做打包贴图、皮肤 PNG、地图、资源文件、截图和 demo。这些属于资源迁移，不是配置包最小闭环。
禁止导出 API key、账号 token、中心服凭据或本地隐私数据，除非后续有明确敏感项审查。配置文件里可能包含翻译服务 key，P0 应默认排除敏感配置域或做文本过滤。

② 包结构

P0 建议把 .qmconfig 定义为 ZIP 容器，但实现文档和 UI 对用户只暴露一个扩展名。包内路径固定，避免未来迁移无法识别。

example.qmconfig
├── manifest.json
└── files/
    ├── QmClient/settings_qmclient.cfg
    ├── QmClient/qmclient_profiles.cfg
    ├── QmClient/qmclient_chatbinds.cfg
    └── QmClient/qmclient_warlist.cfg
文件要求说明
manifest.json必选。记录 schema、导出时间、客户端版本、包含的配置域、是否过滤敏感项。
files/...可选多项。只允许白名单路径，不允许 ../、绝对路径或任意文件名。
压缩格式ZIP 或项目已有压缩能力。如果当前代码没有合适 ZIP 依赖，P0 可先以目录导出规格落地，再评估打包实现。
 
{
  "schema": "qmclient.config_package.v1",
  "exported_at_local": "2026-06-16T23:30:00+08:00",
  "client": {
    "name": "QmClient",
    "version": "unknown"
  },
  "domains": [
    {
      "domain": "QMCLIENT",
      "path": "QmClient/settings_qmclient.cfg",
      "sensitive_filter": "api_keys_removed"
    }
  ]
}

③ P0 导出范围

配置域P0 默认处理规则
QMCLIENT可选/默认谨慎包含大量 Qm/TClient 设置，但可能有翻译 API key；P0 必须过滤 qm_translate_*_key、SecretId/SecretKey 等敏感项，或默认不导出。
TCLIENTPROFILES默认导出皮肤 profile 配置，适合作为迁移目标。
TCLIENTCHATBINDS默认导出聊天绑定，适合跨设备迁移。
TCLIENTWARLIST用户确认可能包含玩家名/备注等社交信息，导出前需要显式勾选。
DDNETP0 不导出覆盖面大，包含上游设置、收藏和未知命令，冲突/隐私风险高。

④ 导入策略

  • 导入前解析 manifest，显示包含哪些配置域、导出时间、客户端版本和敏感项过滤状态。
  • 只允许导入白名单路径，拒绝绝对路径、上级目录跳转和未知文件。
  • 导入前把当前目标文件复制到 QmClient/import-backups/YYYYmmdd-HHMMSS/。
  • P0 使用“文件级替换”，不做逐变量合并；UI 文案必须明确会覆盖对应配置文件。
  • 导入完成后提示重启或重新加载配置，不在运行时强行执行整包 cfg。

如果未来要做智能合并，必须先定义每个配置域的语义和冲突策略。尤其 QMCLIENT 域里混有 TClient、QmClient 和敏感服务配置，不能只按文本行合并。

⑤ 验收

检查项验收标准
导出能生成 .qmconfig，manifest 可读，包内只含白名单路径。
敏感项默认导出不会包含翻译 API key、SecretId、SecretKey 或其它已列敏感项。
导入导入前显示摘要，导入后目标配置文件替换成功，原文件进入 backup 目录。
安全恶意路径、缺 manifest、未知 schema、未知文件和损坏包均被拒绝且不改现有配置。
验证实现后至少跑文档 gate、quick gate 或导出/导入临时目录手动验证，并回填 配置导入导出现状。
