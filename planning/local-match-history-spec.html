本地跨局战绩历史最小版规格

本页把旧持久化统计计划和新版 TODO 的复盘方向收敛为一个本地 sidecar 小规格。当前代码已有 statboard、自动 CSV、PlayerStats HUD、中心服 playtime；本规格只补“本地玩家每局摘要历史”，不做账号、云同步、成就或图表库。

① 目标与非目标 ② 数据来源 ③ Schema 草案 ④ 隐私与存储 ⑤ 验收 ⑥ 当前证据

① 目标与非目标

类型范围理由
目标记录本地玩家每次会话/每局结束时的摘要。补足“CSV 是快照、PlayerStats 是当前会话 HUD、playtime 是在线时长”的空白。
目标使用 QmClient 本地 sidecar 文件，不改 statboard CSV 和中心服 playtime。避免把不同统计线混成一个大系统。
目标保留 JSON 导出能力，后续 UI 可以读取同一份本地历史。先有稳定数据，再考虑列表、筛选或图表。
暂不做账号系统、云同步、KoG 组队榜、成就、排行榜。新版 TODO 已排除成就；远端同步和排行需要服务端、隐私和公平性设计。
禁止把中心服 playtime 当作战绩历史，或把 statboard CSV 路径顺手重构。playtime 与战绩语义不同；CSV 路径 mismatch 应另开 bug 修复任务。

② 数据来源

来源可记录P1 使用方式
Statboardfrags、deaths、suicides、spree、weapon F/D、flag、ingame ticks。只记录本地玩家或 dummy 的摘要，不复制全服所有玩家历史。
PlayerStats HUDalive time、rescue/freeze、hook left/right、map progress。记录本地玩家当前会话指标，用于复盘自己行为。
连接上下文server、map、game type、start/end time。用户可选择是否保存 server/name 这类敏感字段。
Playtime中心服累计在线秒数。不写入每局战绩；最多作为页面旁路展示。
自动 CSV当前局 CSV 快照。不作为历史数据库来源；路径 mismatch 需单独复核。

③ Schema 草案

建议路径：qmclient/stats/local_match_history.jsonl，一行一个 JSON object，便于追加和截断。

{
  "schema": "qmclient.local_match_history.v1",
  "started_at_local": "2026-06-16T22:10:00+08:00",
  "ended_at_local": "2026-06-16T22:35:00+08:00",
  "source": {
    "trigger": "gameover",
    "server_saved": false,
    "map_saved": true
  },
  "context": {
    "map": "Kobra 4",
    "game_type": "DDraceNetwork"
  },
  "local_player": {
    "dummy": 0,
    "frags": 0,
    "deaths": 0,
    "suicides": 0,
    "ingame_ticks": 12345,
    "alive_seconds_total": 220,
    "alive_seconds_max": 80,
    "freeze_count": 3,
    "rescue_count": 2,
    "hook_left_count": 15,
    "hook_right_count": 18,
    "map_progress": 0.72
  }
}
  • JSONL 比单个大 JSON 数组更适合追加；损坏时也更容易保留已有行。
  • 字段只保存摘要，不保存完整聊天、输入历史、IP 地址或服务器密码。
  • 如果同一会话有 main/dummy 两组数据，可写两条记录或在 players 数组中保存；P1 先任选一种并固定。

④ 隐私与存储

项目要求
默认开关建议默认关闭，或首次进入功能页时明确提示本地保存内容。
配置命名新增配置使用 qm_stats_history_*，不新增 cl_stats_*。
存储上限至少支持最大记录数或最大文件大小，防止长期增长。
删除用户必须能一键清空本地历史文件。
敏感字段服务器地址、玩家名、clan 默认不保存或可单独关闭；地图名可保存但应可关闭。

⑤ 验收

检查项验收标准
默认兼容关闭历史记录时，statboard、CSV、PlayerStats HUD、playtime 行为不变。
记录生成启用后，一局结束或离服时追加一条合法 JSONL 记录。
数据分层不会把中心服 playtime 写成战绩，也不会依赖自动 CSV 文件解析。
存储限制达到最大记录数/文件大小后按明确策略裁剪。
隐私禁用 server/map/name 字段后，新增记录不再包含对应信息。
验证记录实现后回填 persistent-stats-status.html 和 innovation-roadmap.html。
