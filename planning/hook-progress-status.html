当前事实

领域状态当前实现影响
核心数据availablem_HookState、m_HookTick、m_HookedPlayer、m_EndlessHook 都能从 character core / DDNet flags 读取。客户端有计算显示的基础数据，不需要改协议。
钩住玩家超时knownHOOK_GRABBED 后 m_HookTick 递增；钩住玩家时超过 SERVER_TICK_SPEED + SERVER_TICK_SPEED / 5 会断开。玩家钩进度能按 1.2 秒上限估算。
钩住地面时长tuning-sensitive发钩时 m_HookTick 会按 1.25f - m_Tuning.m_HookDuration 初始化，可能为负。旧案直接用 HookDuration 除法过于简化；需处理负 tick 和调谐。
0.7 快照兼容special case服务端给 0.7 客户端时会把负 m_HookTick 裁到 0，避免协议无效。如果显示逻辑依赖负值，跨版本观感可能不同，文档/实现要说明。
无限钩implemented iconm_EndlessHook 会进入 DDNet flags；HUD 玩家状态栏已有 endless hook 图标。旧案“无限钩不够醒目”更准确地说是 tee/nameplate 附近没有提示。
名字板强弱钩implementedCNamePlatePartHookStrongWeak 和 CNamePlatePartHookStrongWeakId 已占用 hook 行，且有 qm_nameplate_hook_offset_x/y。新增进度条不能简单塞到同一行，必须设计布局和偏移兼容。

旧计划修正

旧判断/方案当前修正
新增配置写入 config_variables_qimeng.h。该路径已过时；若新增配置，应使用 config_variables_qmclient.h，并遵循 qm_ / Qm 前缀。
只在 nameplates.cpp 添加 CNamePlatePartHookTimer。需要先决定名字板行布局。当前已有 hook strong/weak row 和偏移配置，进度条可能需要独立 row 或作为现有 hook row 的可选子项。
m_EndlessHook 时显示 Unicode ∞。可以作为视觉方向，但当前已有 HUD skin sprite。优先考虑复用 sprite 或小图标，避免字体/Unicode 渲染差异。
默认用绿黄红渐变和低时间闪烁。红绿依赖要和 无障碍与可读性现状 对齐；闪烁默认可能干扰，建议先关闭默认。
所有人显示钩子进度。默认应关闭或仅自己/观战目标，避免多人场景名字板噪声和公平性争议。

建议下一版最小计划

优先级主题范围验收点
P0只读诊断公式先写一个小规格确认 HOOK_GRABBED、m_HookedPlayer、负 m_HookTick、HookDuration 和 endless hook 的显示公式。公式覆盖钩住玩家、钩住地面、endless hook、0.7 裁剪说明。
P1仅自己/观战目标显示默认关闭，开启后只对 local player 或 spectated player 显示，先不做所有人。多人场景不刷屏；观战时目标切换能跟随。
P1HUD 状态栏增强优先在现有 HUD capability 区域补剩余比例或强化 endless icon，而不是改名字板布局。不影响名字板强弱钩和现有 offset 配置。
P2名字板版本如果需要贴近 tee，再新增独立 hook timer row 或现有 hook row 子项。强弱钩图标、强弱 ID、hook timer 不重叠；qm_nameplate_hook_offset_x/y 仍生效。
P3颜色/动画增强在无障碍口径确定后再加颜色渐变、闪烁或断开动画。提供非红绿方案和关闭闪烁选项。
