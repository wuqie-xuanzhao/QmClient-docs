HUD 与视觉辅助现状

本页接管旧 hud-editor-plan.md 和 weapon-switch-animation-plan.md 的 HUD/视觉辅助入口。钩子进度条已拆到 hook-progress-status.html，无障碍已拆到 accessibility-status.html；继续开发前应先读对应 HTML 状态页。

当前已存在的能力

领域状态当前实现说明
HUD 编辑器implementedCHudEditor 已接入 CGameClient，支持可见模块收集、拖拽、滚轮缩放、边缘/中心/其它模块吸附、默认重置和配置保存。旧文档中“缺少重置”“缺少对齐辅助”的结论已过时。
HUD 布局持久化implementedqm_hud_editor_layout 保存元素 token、位置 permille 和缩放百分比。当前不是 JSON 文件导入/导出，而是配置字符串；若要分享布局，需要另写小规格。
武器切换动画implementedqm_weapon_switch_anim 和 qm_weapon_switch_anim_scope 已存在，CPlayers 在武器变化时添加 0.3s 位移和旋转过渡。旧文档把甩枪动画写成待实现项，已不符合当前代码。
武器辅助线implementedCQmWeaponTrajectory 和 qm_weapon_trajectory* 配置已存在。视觉辅助规划时应和现有弹道辅助线统一考虑，而不是重新建一套武器辅助系统。
名字板强弱钩implementedCNamePlatePartHookStrongWeak 和 CNamePlatePartHookStrongWeakId 已渲染强弱状态；qm_nameplate_hook_offset_x/y 控制偏移。钩子进度条布局口径见 hook-progress-status.html。
无限钩 HUD 图标implementedCHud::RenderPlayerState 会在玩家状态栏渲染 m_SpriteHudEndlessHook。“无限钩完全不可见”不准确；更准确的问题是名字板/tee 附近没有剩余时间或醒目提示。
专门无障碍模式split out专门色盲/高对比/焦点导航缺口已拆到 无障碍与可读性现状。本页只保留 HUD、钩子进度条、武器动画等视觉辅助口径。

旧计划修正

旧计划点当前判断处理方式
HUD 编辑器需要新增网格吸附、对齐辅助、重置默认布局。已部分实现当前已有边缘/中心/其它模块吸附和重置默认；后续只保留“预设布局、导入/导出、分享布局”方向。
HUD 布局导出为 JSON。仍是规划不要绕过当前 qm_hud_editor_layout。如要做分享，应先定义从配置字符串到外部文件的迁移/兼容策略。
钩子剩余时间进度条。已拆独立页当前入口见 hook-progress-status.html；实现前需复核预测、调谐、0.7 负 tick 裁剪和名字板布局。
甩枪动画需要新增本地/远程同步方案。已实现本地范围配置当前范围是 self/local/all，不是旧文档的 HTTP 远程开关同步；不要再把它当作未实现 P0。
无障碍从零开始。已拆独立页专门模式缺失但已有分散可读性控制；当前入口见 accessibility-status.html。
配置新增到 config_variables_qimeng.h 或使用 qmc_ 前缀。过时当前 QmClient 配置主文件是 config_variables_qmclient.h，新配置应使用 qm_ / Qm 前缀。

建议下一版最小计划

优先级主题范围验收点
P0HUD 编辑器状态固定把当前拖拽、缩放、吸附、重置、布局存储能力补入用户文档或设置帮助。不再出现“HUD editor 没有对齐/重置”的旧结论。
P1HUD 布局导入/导出只围绕 qm_hud_editor_layout 做文件包装，不新增第二套布局格式。导出的文件能恢复当前布局，并能处理未知元素 token。
P1钩子进度条最小版从 钩子进度条现状 继续，先做只读公式和仅自己/观战目标显示。HOOK_GRABBED 且非 endless 时能显示剩余比例；endless 时不误显示倒计时。
P2视觉辅助颜色入口如涉及 ping/状态红绿依赖，先跳转到 无障碍与可读性现状 复核当前口径。至少一条当前红绿依赖路径可以切换到非红绿方案，并有设置入口。
P3武器切换动画增强只在现有 qm_weapon_switch_anim 基础上调参或增加风格，不再重建同步系统。不改变武器语义、预测和网络协议。
