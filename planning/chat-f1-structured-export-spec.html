F1 聊天结构化导出小规格

本页把新版 TODO 中的 JSON/TOML 导出想法收敛为一个后续可开发的小规格。当前代码已经支持 TXT/HTML/PNG，本页只定义新增结构化格式的边界。

① 目标与非目标 ② 格式选择 ③ Schema 草案 ④ UI 与性能 ⑤ 验收 ⑥ 当前证据

① 目标与非目标

类型范围理由
目标在现有 Select export 选择模式上新增一种结构化导出格式。复用当前选择、过滤和输出目录，不重建 F1 控制台。
目标固定 schema，包含导出元数据、客户端版本、过滤范围和选中聊天行。让后续工具、复盘或分享能稳定解析。
暂不做完整 F1 系统消息、echo、命令历史、远程 rcon 导出。范围和隐私风险不同，不能混入 P0。
暂不做举报平台、自动上传、签名证明、云同步。需要账号、服务端和隐私策略，属于另一个项目。
禁止用 cl_ 前缀新增 QmClient 配置。如需要开关，应使用 qm_ / Qm，但 P0 默认不新增配置。

② 格式选择

P0 建议只实现 JSON，不同时做 TOML。原因是导出结果需要表达数组、元数据和多行文本，JSON 更适合给外部工具稳定消费；TOML 可以在后续作为人工可读配置/审阅格式再评估。

格式本规格建议说明
JSONP0结构稳定，数组天然，方便后续脚本和网页读取。
TOMLP1 或后续人工可读，但多行消息和数组表会让导出更啰嗦。
HTML / PNG / TXT已存在保持现状，不借本规格重写。

③ Schema 草案

输出路径沿用现有目录：qmclient/chat_log/local_chat_export_YYYY-mm-dd_HH-MM-SS.json。字段名使用英文，字符串内容保留原始消息。

{
  "schema": "qmclient.chat_export.v1",
  "exported_at_local": "2026-06-16T23:30:00+08:00",
  "client": {
    "name": "QmClient",
    "version": "unknown-or-build-version"
  },
  "source": {
    "console": "local",
    "filter": "players",
    "selection_mode": "manual"
  },
  "counts": {
    "selected": 2
  },
  "lines": [
    {
      "index": 0,
      "export_id": 123,
      "category": "player",
      "time_text": "23:29",
      "name": "player",
      "message": "hello",
      "raw_text": "[23:29][chat]: player: hello"
    }
  ]
}
字段要求备注
schema固定字符串。后续 schema 变更必须升版本。
exported_at_local本地时间，带时区。文件名时间和 JSON 内时间应一致或可解释。
client.version能取到版本就写版本，取不到写 unknown。不要为了这个字段先改版本系统。
source.filterP0 固定为 players。完整 F1 导出后续再扩。
lines[].raw_text保留当前导出使用的显示文本或原始 backlog 文本。P0 不要求完美拆分玩家名和消息；能拆就填，不能拆可留空。

④ UI 与性能

  • 入口沿用本地 F1 控制台的导出选择模式，优先在 Export selected 附近增加格式选择或下拉。
  • 默认导出仍可保持 TXT/HTML/PNG；JSON 可以是额外勾选项，避免破坏现有工作流。
  • P0 只处理玩家聊天导出，不改变 IsChatExportableEntry() 的范围。
  • 大 backlog 导出必须避免 UI 长时间无响应；若实现仍在主线程，应至少对 1000 行级别导出做一次手动/脚本验证。
  • 失败时应复用现有导出结果反馈，不新增复杂通知系统。

⑤ 验收

检查项验收标准
功能选中玩家聊天后能生成 .json 文件，且不影响现有 TXT/HTML/PNG。
Schema生成文件包含 schema、exported_at_local、source、counts、lines。
边界未选中消息时不生成空误导文件，或生成文件中 counts.selected 明确为 0 并有 UI 反馈。
性能大量消息导出不会造成明显无响应；如无法保证，规格必须降级为后续需要分帧/后台写入。
验证实现后至少运行文档 gate、相关单测或最小手动导出检查，并把证据写回状态页。
