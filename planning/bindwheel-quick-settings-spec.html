BindWheel 快捷设置面板小规格

本页把“BindChat/BindWheel 产品化”拆成一个可控创新小规格：在现有 BindWheel 轮盘和设置页编辑器基础上，新增少量客户端设置白名单预设，让玩家能把常用开关放进轮盘；不重写 DDNet bind，不做宏、插件或 TAS。

① 目标与非目标 ② 数据与命令模型 ③ 白名单建议 ④ UI 与交互 ⑤ 验收 ⑥ 当前证据

① 目标与非目标

类型范围理由
目标在 BindWheel 设置页提供“添加快捷设置”入口，把少量安全客户端开关生成为普通 bindwheel 命令。复用当前 add_bindwheel、轮盘渲染、保存和按键绑定，不新建第二套轮盘系统。
目标固定 P0 白名单，只允许本地表现层、HUD、翻译、截图/资源辅助这类低风险开关。避免把控制台任意命令包装成宏平台。
暂不做多级轮盘、条件宏、延迟命令、脚本 API、插件自动加载。这些会进入自动化/脚本平台风险，不属于快捷设置面板。
暂不做重写 DDNet 原生 bind、Chat Binds 或现有 BindWheel 配置格式。当前三层 bind 能力边界不同，P0 应避免迁移成本。
禁止加入影响物理、预测、协议、输入录制、自动玩法或远端同步的设置。快捷入口不能改变玩法公平性和 DDNet 兼容性。

② 数据与命令模型

P0 不新增持久化结构。快捷设置预设最终仍落成现有 BindWheel 的 name + command，由 ConfigDomain::QMCLIENT 保存。

项目规格边界
名称使用用户可见短名称，例如 Hitbox、Auto translate、Focus Mode。仍受 BINDWHEEL_MAX_NAME = 64 限制。
命令生成单条控制台命令，优先使用 toggle <config> 0 1 或已有显式命令。不生成多命令串，不生成带等待/循环/条件的命令。
来源标记P0 可以只在 UI 上标识“Preset”，不写入配置。如果未来需要区分用户自定义和预设，另行设计 metadata。
保存沿用当前 add_bindwheel "name" "command" 写出。不引入 .qmconfig 或独立 JSON sidecar。

③ 白名单建议

白名单必须小而稳。以下是 P0 可选候选，不要求一次全部实现；实现前仍需逐项确认配置存在、含义清晰、不会触碰玩法逻辑。

分组候选设置命令形态理由
视觉辅助qm_hitbox_mode、qm_show_collision_hitboxtoggle ... 0 1纯本地可视化，适合作为轮盘快速开关。
HUD/可读性qm_ui_motion_level 降级切换、Focus Mode 对应命令/绑定。优先用已有命令；没有稳定命令则暂缓。玩家常在录制、低性能或专注场景切换。
聊天/翻译qm_translate_auto、qm_translate_auto_outgoing。toggle ... 0 1当前已有输入框按钮，但放进轮盘可服务手柄/快捷操作。
资源/截图截图、打开资源目录、切换资源预览调试类入口。仅允许已有显式命令。如无当前稳定命令，P0 不新增。
分身辅助qm_dummy_miniview、qm_dummy_miniview_auto。toggle ... 0 1本地 UI 辅助，可作为高价值候选。

不要把 kill、移动输入、武器切换、投票、聊天刷屏、自动回复、自动操作或服务端命令加入预设白名单。用户仍可手写任意 bindwheel 命令，但“快捷设置面板”不应主动推荐高风险命令。

④ UI 与交互

  • 在现有 BindWheel 设置页编辑器旁增加一个紧凑的 preset 区域，使用分组下拉或简短列表。
  • 选择 preset 后填充当前 Name / Command 输入框，用户确认后仍走 Add Bind 或 Override Selected。
  • 预设项必须显示最终命令，避免用户不知道轮盘会执行什么。
  • 如果当前轮盘已有同名同命令项，按钮应显示为已存在或禁用，避免重复添加。
  • 右侧圆形预览、左键选择、右键交换、中键选择只读行为保持不变。

⑤ 验收

检查项验收标准
功能能从 preset 添加至少 3 个白名单设置到 BindWheel，并在轮盘中执行对应 toggle。
兼容原有 add_bindwheel、remove_bindwheel、设置页手写 Name/Command、轮盘预览和 +bindwheel 不回归。
持久化重启后 preset 生成的条目仍以普通 bindwheel 配置恢复，不需要新文件。
安全preset 列表不包含服务端命令、聊天刷屏、自动输入、物理/预测/协议相关开关。
验证实现后至少跑文档 gate、相关 quick gate 或手动设置页/轮盘截图检查，并回填 Bind 系统现状。
