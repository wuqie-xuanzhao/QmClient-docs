QmClient 自动更新现状

本文接管旧自动更新报告。当前代码里同时存在 QmClient/TClient 侧版本检测与 Windows exe 替换、以及 DDNet 风格的引擎 updater。旧文档把它们写成一个完整自动更新系统，容易误导后续规划。

当前结论 QmClient 版本检测 引擎 updater 仍是规划 旧文档修正 复核证据

当前结论

能力状态维护口径
中心服版本检测已实现TClient 侧请求 /client/version 信息服务，解析 version 字段并比较 QMCLIENT_VERSION。
过旧提示已实现qm_show_outdated_version_warning 控制检测到远端版本较新时是否提示。
Windows exe 下载替换已实现显式更新路径会下载 QmClient/releases/latest/download/DDNet.exe，写临时文件后替换当前客户端。
非 Windows 自动替换TClient 路径未支持TClient 侧 StartUpdateDownload() 在非 Windows 直接提示不支持自动更新。
DDNet 风格 updater存在但需区分CUpdater 仍在，使用 update/update.json 清单和 Q1menG_Client URL；不要和 TClient 侧更新体验混为一条线。
GitHub Releases API / changelog UIplanning未见读取 release body、assets 元数据、跳过版本或更新通道的实现。

准确表述是“已有基础版本检测和 Windows exe 替换能力”。不要把旧方案里的 GitHub API、更新日志、签名校验和跨平台替换写成当前能力。

QmClient 版本检测

环节当前实现边界
检查入口RequestQmClientUpdateCheckAndUpdate() 设置自动更新检查标记并调用 FetchQmClientUpdateInfo()。这是 TClient 组件里的 QmClient 更新路径，不是 CUpdater。
请求 URLQMCLIENT_INFO_URL 拼 ?current=QMCLIENT_VERSION 后发 HTTP GET。信息源是自带服务器，不是 GitHub API。
响应格式FinishQmClientUpdateInfo() 只读取 JSON 的 version 字段。未见 changelog、asset、hash 或 release notes 字段解析。
版本比较IsQmClientRemoteVersionNewer() 去掉 v 前缀，最多比较 4 段纯数字。不支持复杂 SemVer 后缀、预发布标签或 build metadata。
过旧提示远端较新时提示用户去 QQ 群更新。不是完整更新日志 UI，也没有跳过版本状态。
下载替换Windows 下下载 GitHub latest 的 DDNet.exe，完成后替换当前二进制。未见 SHA256 校验、release asset 选择、回滚 UI 或跨平台自动替换。

引擎 updater

src/engine/client/updater.* 保留了 DDNet 风格的 updater 状态机：获取/解析更新清单、下载文件、移动文件、替换 client/server 二进制并设置重启状态。它当前使用的下载源仍指向 wxj881027/Q1menG_Client，和 TClient 侧 QmClient latest exe 下载路径不是同一条实现线。

环节当前行为
编译开关AUTOUPDATE 在 Windows 默认 ON，其他平台默认 OFF；INFORM_UPDATE 仍是独立开关。
清单读取 update/update.json，要求 JSON array，按 version、client、server、download、remove 字段生成任务。
版本停止点遍历清单时遇到 QMCLIENT_VERSION 停止。
替换二进制ReplaceClient() 先把当前执行文件改名为 .old，再把 update/ 中新文件移入；非 Windows 会尝试 chmod +x。
完成状态CommitUpdate() 成功后，在线或编辑器未保存时进入 NEED_RESTART；否则直接重启客户端。

这条线可以作为老更新器能力保留说明。若后续要做现代 QmClient 更新体验，应先明确是迁移它、替换它，还是继续使用 TClient 侧简化下载路径。

仍是规划

  • GitHub Releases API：读取 tag_name、release body、asset 列表、下载大小和发布时间。
  • 更新日志展示：在设置页或弹窗里展示 changelog，而不是只提示去 QQ 群。
  • 跳过版本、稍后提醒、检查间隔、更新通道和仓库配置。
  • 跨平台自动替换、签名校验、哈希校验和失败回滚 UI。
  • 配置版本迁移、data_version.txt 校验和自动更新之间的联动。

CheckDataVersion() 当前仍是 stub；不要把数据版本校验写成已完成更新安全机制。
