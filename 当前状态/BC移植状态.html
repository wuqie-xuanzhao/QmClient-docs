QmClient BC 功能移植现状

本文接管旧 BC 移植调研的当前状态判断。旧报告可以追溯 BC 端思路，但不能继续直接作为 QmClient 实现状态使用；当前结论以 2026-06-16 的 QmClient 源码复核为准。

当前结论

旧“BC 功能移植进度 2/4”已经失效。按当前源码重算，3D Particles、Speedrun Timer、Auto Team Lock 已有 QmClient 版实现；Client Indicator 没有按 BC 的 UDP Presence 复刻，而是被 QmClient 中心服识别、badge 和远程粒子方案覆盖。

Media Background 不能再简单写成“未见实现”：当前已有实体层视频背景和菜单 theme 视频背景基础，但缺 BC 式媒体背景管理/选择的产品化闭环；边界见 媒体背景边界.html。Finish Prediction 和 Split Timer 仍不能写入当前已完成清单；Finish Prediction 边界见 完赛预测边界.html。

已落地功能

Client Indicator

当前 QmClient 没有照搬 BC 的 UDP Presence。用户识别来自中心服同步和本地 brand 表，展示面分成两类：scoreboard 上的 Qm / Arg badge，以及远程玩家 foot trail。

  • qm_client_show_badge 控制 scoreboard badge。
  • qm_client_mark_trail 控制远程粒子，且只有对方同步为本地粒子和远程粒子都开启时才渲染。
  • 设置入口在 Qm 设置页的 “Dream Features” 模块。

3D Particles

3D 背景粒子已经是当前功能，不再是待移植项。实现位于 src/game/client/components/tclient/background_particles.*，组件注册在 game client 渲染链中，位置在普通 map background 之前。

  • 形状包括 Cube、Heart、Sphere、Pyramid、Diamond、Ring、Star、Crescent，Mixed 会在这些真实形状中随机。
  • 运行时支持数量、透明度、大小、速度、深度、视野 margin、颜色模式、拖尾、辉光、脉冲、闪烁、玩家推开和粒子碰撞。
  • 渲染使用线框形状、基于 depth 的 parallax 和 render order 排序，视野跳变时会重置粒子分布。
  • 设置入口是 “3D Background”，配置变量统一为 qm_3d_particles*。

Speedrun Timer

当前 Speedrun Timer 是 HUD 倒计时实现，不是单纯规划。它使用小时、分钟、秒、毫秒的新配置组合总时长，同时兼容旧 qm_speedrun_timer_time 的 MMSS 格式。

  • 只有 race 已开始时显示倒计时；过期后调用 SendKill()。
  • qm_speedrun_timer_auto_disable 开启时，过期后会自动关闭总开关。
  • 设置入口是 “Speedrun Timer”，可直接调节 hours / minutes / seconds / milliseconds。

Auto Team Lock

Auto Team Lock 已经进入 CGameClient::UpdateAutoTeamLock()。在线状态下，它按当前 dummy 跟踪本地玩家队伍；进入可锁队伍且队伍变化后，按配置延迟发送 /lock 1。

  • 只对 TEAM_FLOCK 和 TEAM_SUPER 之间的可锁队伍生效。
  • 离线、无本地 client id 或关闭配置时会清理 pending 状态。
  • 设置入口在 HJ 辅助模块，包含开关和 0-30 秒延迟。

未见实现和 Backlog

新版 TODO PDF 可以作为后续规划参考，但当前状态页不能把未复核或未落地条目写成完成。按当前源码复核，以下内容仍应留在 规划/backlog：

  • Media Background 产品化：底层图片/视频背景加载已存在，但仍缺独立媒体库、导入/删除、播放控制、音频策略、菜单/实体背景统一管理和性能验收；详见 媒体背景边界.html。
  • Finish Prediction：未见 finish prediction 相关符号或渲染入口；Race Time、Speedrun Timer、Split Timer、Gores 进度和 AntiPing 预测都不能等同，边界见 完赛预测边界.html。
  • Split Timer：未见 split timer 相关符号或 qm_split 配置；最小规格见 分段计时检查点.html。

如果后续继续整理 planning，建议把这些候选项拆成独立 HTML 页，分别写清目标、非目标、源码现状和验证口径。
